# Quality Performance Dashboard
 
## Overview
 
Interactive Power BI dashboard designed to monitor manufacturing quality performance and identify the main sources of defects.
 
## Business Problem
 
Production and quality managers need a clear overview of quality metrics to identify underperforming production lines, monitor defect trends, and prioritize corrective actions.
 
## Dashboard Features
 
- Quality KPI monitoring
- Production line comparison
- Pareto 80/20 analysis
- Defect type analysis
- Target vs Actual defect rate tracking
- Product-level quality analysis
- Monthly quality trends
 
## Tools Used
 
- Power BI
- Power Query
- DAX
 
## Key Insights
 
- Line C showed the highest defect rate (3.56%)
- Line D achieved the best quality performance (1.75%)
- Surface defects represented the largest share of total defects
